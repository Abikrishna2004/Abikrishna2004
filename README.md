## ⚙️ Setup Guide (one-time)

1. Create a **new GitHub repository** named exactly `Abikrishna2004` (must match your username), set it to **Public**.
2. Upload this single file as `README.md` at the root of that repo — it will automatically become your profile page.
3. Before uploading, personalize these placeholders:
   - `youremail@example.com` → your real email
   - `linkedin.com/in/abikrishna` → your actual LinkedIn URL
   - `instagram.com/yourhandle` → your actual Instagram URL
4. **(Optional, for the snake animation)** Create a second file in the same repo at `.github/workflows/snake.yml` and paste in the YAML block from the "Contribution Snake" section above. Then go to **Settings → Actions → General → Workflow permissions** and set it to **"Read and write permissions"**. Run the workflow once manually from the **Actions** tab — it'll refresh daily after that.

That's it — your profile will show the animated banner, typing text, tech badges, projects, live stats, streaks, trophies, and (optionally) the snake animation.
